# Pallet Flow

A live top-down simulation of a warehouse, its forklifts, a truck fleet and three stores. Change the number of forklifts, trucks, truck size and shopper demand, and watch the bottleneck move. Demonstrates the Theory of Constraints and basic queueing.

**Live:** https://caselka.github.io/pallet-flow/

One self-contained `index.html`. No build step, no libraries. Open the file or visit the link.

Part of Abstract Projects: small interactive pages that make abstract ideas something you can poke at.
